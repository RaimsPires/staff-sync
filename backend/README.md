# StaffSync backend

FastAPI modular monolith (PostgreSQL 16 + PostGIS, Redis, ARQ worker) serving the admin dashboard and the mobile app
under `/api/v1`. Design: `../Backend API.md`.

## Run locally

Shortcut: `make dev` (or `./scripts/dev.sh`) does everything below, then serves on http://localhost:8000/api/v1/docs.

```bash
docker compose up -d                  # PostGIS on :5433, Redis on :6380 (ports avoid other local containers)
cp .env.example .env
uv sync
uv run alembic upgrade head           # runs as the owner role; the API connects as the least-privilege role (RLS applies)
uv run uvicorn staffsync.main:app --reload     # http://localhost:8000/api/v1/docs
uv run arq staffsync.workers.settings.WorkerSettings   # outbox relay, absences, reminders, retention
```

In dev, e-mail/SMS codes are written to the server log (`notify` lines) instead of being sent.

## Tests

```bash
uv run pytest        # needs `docker compose up -d`; creates a throwaway `staffsync_test` database
uv run ruff check src tests
```

## Layout

`src/staffsync/` — `core/` (config, db, security, deps, errors, audit, outbox), `common/` (base repository, geo, pagination),
`modules/<name>/` (router → service → repository/models), `workers/`, `migrations/`.
Migrations: `0000` extensions, `0001` schema (autogenerated), `0002` Row-Level Security + grants.
While the schema is still moving, `scripts/regen_migrations.py` rebuilds the chain.

## What is real and what is a stub

Real and tested: auth (password+TOTP, mobile OTP, refresh rotation with reuse detection), companies/branches/sites with PostGIS
geofences, employees/devices/CSV import, roles & scopes, schedules and shift expansion, the check-in pipeline (offline sync,
proxy, PIN lockout), alerts/corrections, leave, audit, dashboard, reports (CSV/XLSX), webhooks, Stripe webhook handling, soft delete/trash.

Stubs / need credentials: SMS/e-mail/push providers (console adapter), S3 (local fake unless `S3_BUCKET`), Play Integrity /
App Attest verification, SSO (Authlib endpoints return `SSO_NOT_CONFIGURED`), PDF exports, scheduled report e-mails, Stripe
checkout/portal (need `STRIPE_SECRET_KEY` and `STRIPE_PRICES`).
